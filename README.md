## Что умеет

- Экран компьютера на телефоне или планшете по Wi‑Fi: зеркало или отдельный монитор, касания и перо
- Файлы в обе стороны, фото телефона на ПК, уведомления телефона на ПК
- Экран, камера и микрофон телефона — на компьютер
- Подключение по QR-коду, шифрование сеанса (AES-256-GCM с PIN), только локальная сеть, без облака и аккаунта
